## 现有初步结论（待你独立核验）

- 手机/平板/PC/2in1 上代理提醒**受管控**：三方应用需先向华为申请"代理提醒开放能力"权益（约 8 个工作日，通过后调试与发布须手动签名），未开通时 publishReminder 失败。
- 应用类型/场景限制：KeepFresh 属"生活服务类"且"临期提醒"在允许场景内，符合申请条件。
- 单应用有效提醒 ≤30；周期性提醒（如每日重复）无论是否点击关闭都永续占位。
- 内容发布时固定，更新 = cancelAllReminders() 后重新 publishReminder。
- App 未启动时内容停留在上次发布快照（更新必须由应用进程执行）。
- 点击仅能跳回本应用，wantAgent 指定 pkgName+abilityName。
- 权限：ohos.permission.PUBLISH_AGENT_REMINDER 静态声明 + 通知授权；模拟器 API 20 起可调试。
- "每天固定时刻"用闹钟型（ReminderRequestAlarm + daysOfWeek）。
