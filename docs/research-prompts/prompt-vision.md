## 现有初步结论（待你独立核验）

- Core Vision Kit **没有**图像分类 API（官方 API 目录、Kit 介绍页、ctx7 检索均未见）。
- textRecognition：API 10+ 可用，输入 PixelMap（RGBA_8888），输出 blocks→lines→words 纯文本+坐标，无结构化字段；印刷体可用、手写弱、喷码点阵无官方口径需真机实测；仅支持中国大陆、不支持模拟器。
- cameraPicker：API 11+，免 CAMERA 权限，pick() 返回 resultUri；CameraKit 需 CAMERA 权限+会话管理，对本场景不必要。
- objectDetection：API 12+，15 类数字编码标签，仅"食物(11)"可映射 KeepFresh"食品"。
- 自动分类到"饮料"级不可行；退化方案 = OCR 抽日期 + 人工选分类。
