# KeepFresh 界面设计规范

> ⚠️ **已废弃**：本文件是旧版「清新自然」设计规范存档，已被根目录 `DESIGN.md`（包豪斯：暖白纸底 + 三原色几何 + 硬阴影 + 零圆角）取代。页面实现以 `common/Theme.ets` 令牌 + `DESIGN.md` 为准，本文件仅保留溯源。

> 风格方向：清新自然（Fresh & Natural）  
> 目标：让保质期管理 App 看起来清爽、可信、有温度，减少用户面对「临期 / 过期」时的焦虑感。

---

## 1. 设计原则

1. **清透呼吸感**：大面积奶白/薄荷白背景，少分隔线，靠留白和阴影区分层级。
2. **状态一目了然**：过期用柔和珊瑚红、临期用暖橙、安全用薄荷绿，避免高饱和警示色带来的压迫感。
3. **圆润友好**：大圆角卡片（20px）和胶囊按钮，降低工具感。
4. **信息分层**：标题 / 数字 / 辅助说明有明确的字重、字号、颜色对比。
5. **品牌一致性**：所有页面共用 `Theme.ets` 令牌，避免每个页面复制色值。

## 2. 色彩系统

### 2.1 主色

| 名称 | 色值 | 用途 |
|------|------|------|
| 主色 Brand | `#34C759` | 主按钮、选中状态、关键数字、强调图标 |
| 主色浅 BrandSoft | `#E8F8EC` | 轻量背景、选中 Chip、状态条轻态 |
| 主色深 BrandDark | `#28A745` | 悬停/按下加深、完成状态 |

### 2.2 背景

| 名称 | 色值 | 用途 |
|------|------|------|
| 页面背景 PageBg | `#F7FAF8` | 所有页面底层背景 |
| 卡片背景 CardBg | `#FFFFFF` | 卡片、底部面板、输入框 |
| 输入框背景 InputBg | `#F1F5F2` | TextInput / 选择行背景 |

### 2.3 文字

| 名称 | 色值 | 用途 |
|------|------|------|
| 主文字 TextPrimary | `#1A231E` | 标题、名称、主要数字 |
| 次文字 TextSecondary | `#5A6B62` | 说明、标签、次要信息 |
| 提示文字 TextTertiary | `#8E9E96` | 占位符、禁用态 |
| 反白文字 TextWhite | `#FFFFFF` | 深色背景上的文字 |

### 2.4 状态色

| 状态 | 主色 | 浅色背景 | 用途 |

| 安全 Safe | `#34C759` | `#E8F8EC` | 距到期较远 |

| 过期 Expired | `#FF5A5F` | `#FFEBEE` | 已过期 |
| 危险 Danger | `#FF3B30` | — | 删除、错误 |

### 2.5 中性色

| 名称 | 色值 | 用途 |

## 3. 字体与排版

使用鸿蒙系统默认字体（HarmonyOS Sans）。

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| 页面大标题 | 24vp | Bold | 32 | 首页品牌名 |
| 页面标题 | 20vp | SemiBold | 28 | 二级页标题 |
| 卡片数字 | 32vp | Bold | 40 | 统计数字 |
| 列表主文字 | 16vp | Medium | 22 | 物资名称、设置项 |
| 列表辅助文字 | 13vp | Regular | 18 | 分类、数量、说明 |
| 标签文字 | 12vp | Medium | 16 | 状态徽标、分类标签 |
| 按钮文字 | 16vp | Medium | 22 | 主要操作 |

## 5. 阴影

卡片统一使用柔和投影，提升层级感：

```

offsetY: 4

```

## 6. 组件规范

### 6.1 顶部导航栏

- 高度：56vp
- 背景：透明（随页面背景）
- 返回按钮：40×40 圆角图标按钮，背景 `InputBg`
- 标题：20vp SemiBold `TextPrimary`
- 右侧操作：40×40 圆角图标按钮或 36vp 高胶囊按钮

### 6.2 统计卡片

- 横向三等分卡片
- 圆角 20，白色背景，柔和阴影
- 未选中：无边框或 1vp `Border`
- 选中：2vp `Brand` 描边 + 轻微缩放/高亮
- 数字：32vp Bold，颜色对应状态
- 标签：13vp `TextSecondary`

### 6.3 物资列表卡片

- 白色背景，圆角 20，阴影
- 左侧：分类图标 + 名称/分类数量
- 右侧：圆角状态徽标 pill，显示「剩 X 天 / 今天到期 / 已过期 X 天」及到期日
- 过期/临期卡片左侧加 4vp 彩色竖条装饰

### 6.4 按钮

- 主按钮：`Brand` 背景，白色文字，全圆角（高度的一半），高度 48vp
- 次按钮：白色背景，`Brand` 描边 + 文字
- 图标胶囊按钮：`Brand` 背景，带图标的行内按钮
- 悬浮按钮（FAB）：56×56 主色，圆角 20，阴影更重

### 6.5 输入框 / 选择行

- 背景 `InputBg`，圆角 14
- 内边距 14
- 右侧带图标（日历、下拉箭头）
- 获得焦点或悬停时边框 `Brand`

### 6.6 Chip 组

- 未选中：`InputBg` 背景，`TextPrimary` 文字
- 选中：`Brand` 背景，白色文字
- 圆角 18，内边距 8×16

### 6.7 设置项

- 白色卡片，圆角 20，阴影
- 每行左侧图标 + 标题 + 说明
- 右侧开关、箭头或数值
- 行之间用 1vp `Divider` 分隔

---

## 7. 空状态与提示

- 空状态使用柔和图标（SymbolGlyph：`archivebox` / `leaf`）
- 主文案 16vp `TextSecondary`
- 辅助文案 14vp `TextTertiary`
- 提供主操作按钮引导用户

---

## 8. 页面级要求

### 首页
- 顶部标题区左侧放品牌名和一句轻 slogan，右侧提醒 + 设置图标
- 统计卡片带图标（全部 🗂️ / 临期 ⏰ / 过期 ⚠️）
- 列表卡片按到期日升序，过期项置顶并带红色左侧条
- FAB 放右下角

### 录入/编辑页
- 顶部返回 + 标题 + 保存按钮
- 第一行放「扫码快填」图标胶囊
- 表单分块：基本信息、日期与保质期、自定义字段、备注
- 到期预览做成突出的绿色卡片

### 详情页
- 顶部大色块 banner 显示状态（过期红 / 临期橙 / 安全绿）
- 下方白色信息卡片分组展示
- 底部固定编辑 + 删除按钮

### 设置页
- 按模块分卡片：临期规则、提醒设置、数据备份、物资扩展、关于
- 每个模块内行item统一左图标 + 右控件

### 自定义字段页
- 字段卡片带类型标签 Chip
- 操作按钮紧凑排列
- 编辑抽屉保持圆角和统一表单风格

---

## 9. 实现约定

- 所有页面统一 `import { Theme } from '../common/Theme'`
- 颜色、字号、间距全部来自 `Theme` 常量，禁止页面内写死色值
- 状态颜色统一通过 `ExpiryService` 获取，包括主色和浅色背景
- 分类图标通过 `CategoryIcons` 映射，未命中返回默认叶子图标
