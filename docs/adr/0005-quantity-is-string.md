# ADR 0005: quantity 用 string（TEXT 列）存储，而非数值类型

- **状态**：已接受 (Accepted)
- **日期**：2026-08-24（pantry-logic 移植）

## Context

从 the-ai-menu 项目 Pantry 模块移植物资生命周期管理时（`D:\a-code\github\the-ai-menu`），需为数量字段定型。用户录入习惯是「500g」「2斤半」这类混合文本，不是纯数字。

## Considered Options

- REAL / 数值列——**否决**：无法承载混合输入；浮点精度坑（0.1+0.2）会渗进求和与并条比较
- **string（TEXT 列）——采纳**：支持混合输入；对齐 `normalizeQuantityUnit` 解析链路；数值运算在解析后按单位内进行。代价：DB 迁移 REAL→TEXT 一次性成本（可接受）、同批次并条的数量求和必须先过解析

## Consequences

- 并条（同批次合并）的数量求和依赖 QuantityUnit 解析；纯文本数量按字符串语义处理
- 后续任何「按数量统计」的需求都必须先过解析层，不得直接对列做算术

## 同批移植的附带决策（过门槛较弱，随本 ADR 记录）

| 决策 | 结论 | 理由 |
|---|---|---|
| AddItem 形态 | 保持整页表单 | 表单含扫码+自定义字段+月数切换，Sheet 化收益不抵重写风险 |
| 状态操作入口 | 详情页按钮 | 与现有编辑/删除入口模式一致，改动集中单页 |
| 回收站 | Settings 子页 | 软删除列表 + 恢复/彻底删除，独立页面不污染主流程 |
| 分类/位置管理 | 完整 CRUD | 新增/重命名/删除/拖拽排序，一步到位 |
| 测试策略 | 纯函数单测（node --test） | 复用 test/ 目录现有模式，还 issue #9 的 ExpiryService 测试债 |

**移植关键不变量**：旧数据兼容（新列全部可空/有默认值）；月数与天数并存时月数优先；终态（已用完/已丢弃）不被过期状态覆盖；软删除不进入任何统计与列表。抄逻辑与页面骨架，不抄视觉风格——所有 UI 走包豪斯令牌（`DESIGN.md`）。
