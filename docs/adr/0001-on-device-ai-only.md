# AI 识别能力仅端侧，禁止云端

KeepFresh 的所有识别能力（扫码、OCR、图像分类）必须使用鸿蒙端侧 Kit（ScanKit、CoreVisionKit）在本机完成，禁止调用任何云端 API（多模态大模型、在线条码库等）。这是产品级硬约束而非实现偏好：个人自用场景优先离线可用、零成本与隐私。

## Considered Options

- 云端多模态 LLM（识别更聪明，但需联网、API key、按次费用）——被否决
- 混合（端侧默认 + 可选云端增强）——被明确否决（用户原话："仅端侧，禁止云端"）
- 端侧 Kit——**采纳**；代价是识别粒度受限：认不出具体品牌，只能给大类建议与文本抽取
