# ADR 0006: 个人日用采用调试签名真机安装（非应用市场分发）

- **状态**：已接受 (Accepted)
- **日期**：2026-09-27
- **决策人**：产品/架构

---

## 1. 背景与问题描述

KeepFresh 进入自用 dogfood 阶段，需要在 Mate 80 Pro Max 上像普通 App 一样打开，不依赖 DevEco Studio 持续连接。HarmonyOS 的发布签名应用不能像 Android APK 那样自由侧载，可选分发通道各有明显门槛。

## 2. 决策考量与候选方案

| 候选 | 结论 | 理由 |
|---|---|---|
| **调试签名装真机（选定）** | ✅ | 零审核、当天可用、覆盖安装不清数据；适合单人自用 dogfood |
| AGC 邀请测试 | 备选 | 体验最接近正式版、免开发者模式，但要 AGC 建应用 + 发布证书 + 测试审核，个人项目阶段尚不必要 |
| 指定设备发布 | ✗ | 仅企业开发者可用，且需自备 HTTPS 分发服务器 |
| 非公开发布 | ✗ | 企业账号 + 工信部备案 + 正式审核，成本远超自用需求 |

## 3. 已落地事实（2026-09-27 真机验证）

- **设备**：HUAWEI Mate 80 Pro Max（HarmonyOS API 26），经无线 HDC 连接（`192.168.6.131:45507`）
- **Profile**：debug 类型，有效期 **2026-08-19 → 2027-08-19**，已登记 2 台设备 UDID
- **安装**：`devecocli run --skip-build` 覆盖安装成功，未卸载旧版，8 条物资 + 使用日志完整保留
- **验证**：UI 树实测首页渲染（`6项 · 1过期 · 0临期`），数据库 `materials` 8 行直查确认

## 4. 影响与约束

- 桌面图标直接启动，**无需连电脑、无需保持 USB/无线调试开启**。
- 更新路径：重开 USB/无线调试 → `devecocli run --module entry --device <serial>`，同签名覆盖不清数据。
- **硬约束**：调试包只能装到 Profile 登记过的设备；换新手机必须先注册新 UDID 重新签名，迁移前先在 App 内「设置 → 数据备份 → 导出备份」。
- 若将来公开发给非开发者手机使用，再升级走 AGC 邀请测试（体验一致，无需开发者模式）。
